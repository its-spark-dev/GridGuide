## Provenance and verification

The actual v1.0.0 application at `b324c1b355cda60035fb11fa32bcddf10931f649` ran with
authorized pinned challenge sources and external AI disabled. The original
`RestorationDecision.tsx` and `CandidateImpactMap.tsx` were unchanged. Each candidate
was selected using its normal UI control, with no fabricated responses, geometry,
DOM changes, image editing or compositing.

All captures use 1440×1200, device scale 1, reduced motion, the same scroll position,
and default critical-proxy policy with one four-person crew and clear access.
Each has one pressed candidate selector, matching inspection heading, twelve decoded
OSM tiles, visible markers, customer areas, legend and attribution. Four candidate IDs
and image hashes are distinct; no browser runtime errors were observed.

The upstream fuse has four dependent premises; the transformer has one and requires
that fuse repair. They share the same generalized spatial footprint. The historical
replay has 23 dependencies across two cells and remains a spatial hypothesis. The
critical-context fuse has one dependency; facility electrical attachment is unverified.
Counts overlap and must not be summed as unique releases.

[Published provenance](grid-insights/provenance.json) records image, source and
implementation hashes, application commit, browser, capture time and viewport.
Private raw capture metadata remains outside the repository; no new coordinate payload,
tile archive or dataset is added. The public package remains non-geographic fiction.

Visible attribution is retained: AEP challenge GIS generalized areas and ©
[OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
The [OSM attribution guidance](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines#Static_images)
and [tile policy](https://operations.osmfoundation.org/policies/tiles/) remain applicable.
Original historical media, Overview, preparedness and team attribution are unchanged.
