GridGuide is an independent outage-concierge prototype built by three teammates for the **AEP AI Outage Concierge Challenge at HackOHI/O 2026**. It connects source-validated utility dependencies with transparent restoration scenarios, interactive maps, and practical customer preparation.

**v1.0.0 presents the hackathon implementation with post-event documentation, an architecture diagram, and authentic application screenshots. Application functionality is unchanged.**

## What you can explore

- **Customer outlook:** an explainable storm concern band and conditional restoration range for one vetted anonymous location, with crew-size and access controls.
- **Repair planning:** four curated candidates, two transparent priority policies, and dependency-aware schedules for one or two crews.
- **Preparation and communication:** guidance adapted to optional session-only declarations, plus four hypothetical message previews.
- **Grounded explanations:** optional Gemini reference selection with server-rendered claims, validated result binding, and Standard explanations that work without external AI.

## Engineering highlights

- **40,779 complete source-validated paths** from 117,599 indexed premise paths. Incomplete memberships withhold impact counts instead of producing partial answers.
- **28 unique premise dependencies across four repair candidates**, with overlap removed and upstream repair constraints preserved.
- **Deterministic calculations separated from AI:** workbook-based repair person-hours remain distinct from conditional elapsed time; AI output is restricted to validated references.

## Verification

On November 3, 2026, **194 Python tests and 49 Chrome browser tests passed**, alongside the strict TypeScript/Vite production build, generated API type consistency, and golden CLI scenarios. These are prototype regression checks, not predictive or operational validation. See the [verification record](https://github.com/its-spark-dev/GridGuide/blob/v1.0.0/docs/releases/VERIFICATION.md) for environment and scope.

## Prototype boundaries

Concern bands are not calibrated outage probabilities, and time envelopes are not confidence intervals or guaranteed restoration bounds. Unknown productivity and operational delays may exceed the displayed range. There is no live utility outage feed. Historical spatial matches and facility proximity do not confirm current damage, electrical attachment, or switching feasibility. Dependency counts are not confirmed restorations. The four-candidate comparison is not system-wide optimization; messages are previews with no delivery or dispatch integration.

Local execution requires the pinned AEP challenge files. Source-data privacy findings and permission boundaries remain documented in the [third-party notices](https://github.com/its-spark-dev/GridGuide/blob/v1.0.0/THIRD_PARTY_NOTICES.md). No project-wide software or data license is added. GridGuide is an independent prototype without AEP endorsement.
