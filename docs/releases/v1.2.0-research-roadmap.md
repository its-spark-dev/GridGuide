# GridGuide v1.2.0 — ML Research Edition (release preparation)

**Status: planned; not yet released.** This page is a release-scope and provenance checklist, **not** a GitHub Release or evidence of completion. The last stable product release remains [v1.1.0](https://github.com/its-spark-dev/GridGuide/releases/tag/v1.1.0).

## Scope and positioning

v1.2.0 is intended to document and preserve the **offline, synthetic ML and scheduling research** undertaken after the stable portfolio product release. It must not imply a new version of the standalone public demo, an operational model deployment, AEP endorsement, real outage performance, or a replacement for v1.1.0's stable package.

## Proposed release notes (draft; edit and verify at release time)

> **GridGuide v1.2.0 — ML Research Edition** archives a reproducible series of synthetic scheduling and machine-learning investigations. The repository contains trained GridGuide-specific Ridge and Random Forest dispatch models, portable validated inference, an adaptive event simulator, independent evaluation reports, and a fresh opportunity audit. The trained policy did **not** beat its median-search teacher on the preregistered quality criterion; an independent follow-up recommends **NO-GO for another immediate training pilot**.
